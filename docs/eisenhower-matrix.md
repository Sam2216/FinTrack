# FinTrack Eisenhower Matrix

## Do — MVP
- Set and update a monthly budget.
- Record expenses with an amount, date, and category.
- Record income separately from the spending budget.
- Display monthly totals and remaining budget.
- Save and reload records between sessions.

## Schedule — V2.0+
- Add savings goals.
- Add category-specific budgets.
- Compare spending across months.
- Edit and delete transactions.

## Delegate — Use a Library
- Use java.time for dates and months.
- Use java.nio.file for reading and writing files.
- Use NumberFormat for currency display.

## Delete — Cut From This Project
- Connect directly to bank accounts.
- Provide investment recommendations.
- Add social profiles or spending leaderboards.
